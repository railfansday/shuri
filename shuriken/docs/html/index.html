Dokumentasi Shuriken 7

Shuriken adalah CLI tool untuk scraping gambar, generate konten blog dengan AI, dan export ke berbagai platform.

💰 Ingin monetize traffic dari site hasil Shuriken? Gunakan Adsterra — ad network yang cocok untuk site baru, tanpa minimum traffic. Tersedia banner, native ads, popunder, dan social bar. Lihat cara pasangnya di Ads & Tracking.

Daftar Isi

Memulai

  • Instalasi — Requirements, install, setup awal
  • Quick Start — Workflow dari nol sampai export

AI & Providers

  • AI Providers — Setup 19+ provider AI (OpenAI, Gemini, Claude, dll)
  • Panduan Biaya AI — Rekomendasi provider berdasarkan budget

Export

  • Platform Export — WordPress, Blogger, Hugo, CSV, Native, HTML
  • HTML Themes — 45 tema + opsi random

Monetisasi

  • Panduan Adsterra & Integrasi Iklan — Trik memasang slot ads dan optimasi revenue

Referensi Command

  • image:scrape — Scraping gambar & generate konten
  • image:export — Export ke berbagai platform
  • clear:data — Bersihkan database dan export
  • token — Kelola API token per provider
  • prompt — Kelola custom prompt template
  • site — Kelola publish destination
  • post:publish — Publish post ke WordPress via API
  • site:deploy — Deploy HTML ke Netlify / Cloudflare Pages
  • mcp:serve — MCP server untuk integrasi Claude Code & Gemini CLI

Case Study

  • Promosi Bisnis Lokal (Agen Umroh) — Keyword lokal, template CTA, topical authority
  • Auto-Blog Resep + AdSense (ARSAE) — Blog resep masak, monetize AdSense tanpa daftar site
  • Affiliate Shopee via Indoleads — Konten produk + deeplink affiliate otomatis
  • Nickname Tier 1 + Adsterra — Niche nickname multi-bahasa, traffic tier 1
  • Niche "Map Of" Tier 1 — Konten peta/lokasi, evergreen, traffic organik stabil
  • Niche PFP (Profile Picture) — Gallery gambar tanpa AI, template kustom, Adsterra
  • Printable Worksheets — Aggregator edu worksheet, trafik Bing Tier 1, AdSense/Adsterra

Lainnya

  • Custom Templates — Buat template konten sendiri tanpa ubah kode inti
  • FAQ & Tips — Solusi umum, tips scraping, dan pertanyaan sering muncul
  • Konfigurasi Lengkap — config/ai.php, shuriken.php, export.php

Ringkasan Fitur

Fitur Detail
Sumber scraping Bing Images
Custom images --images_txt — pakai daftar URL sendiri dari images.txt
AI Provider 19+ provider (15 API + 4 lokal/CLI) + custom OpenAI-compatible
Template prompt 10 built-in (image, recipe, list, review, faq, tutorial, comparison, news, roundup, guide) + custom
Custom content template --template=nama — folder templates/nama/ dengan content.blade.php & title.blade.php
Deploy target Netlify, Cloudflare Pages, Vercel, Surge, GitHub Pages
Format export WordPress XML, Blogger XML, Hugo ZIP, CSV, SQLite, HTML ZIP
HTML Tema 45 tema (11 keluarga × 4 variant + default)
Spintax Ya — variasi teks otomatis {opsi1|opsi2}
Token rotation Ya — round-robin untuk rate limit

Perintah Cepat

# Pipeline otomatis penuh
php shuriken omakase

# Scrape + AI content
php shuriken image:scrape --keywords="resep masak" --ai --provider=deepseek

# Scrape tanpa AI, pakai custom template (misal PFP)
php shuriken image:scrape --keywords="anime pfp" --template=pfp

# Scrape pakai gambar dari images.txt (bukan Bing)
php shuriken image:scrape --keywords="keyword" --images_txt

# Export ke HTML
php shuriken image:export --platform=html --theme=five-dark

# Bersihkan semua data
php shuriken clear:data
